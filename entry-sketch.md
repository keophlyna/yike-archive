## Yike archive entry

One entry records a specific Yike performance, memory, or piece of cultural
knowledge.

| Field          | Required? | What to capture                                              |
| -------------- | --------- | ------------------------------------------------------------ |
| title          | Yes       | A short, descriptive title for the entry                     |
| khmer name     | Yes       | The Khmer name, title, or phrase as performed or remembered  |
| story          | Yes       | The story, performance detail, or cultural knowledge itself  |
| source         | Yes       | The named person or community who shared it                  |
| place          | Yes       | Where the story, performance, or interview belongs           |
| date           | Yes       | When it was collected or when the event happened             |
| photo or audio | No        | A photo or audio recording, when permission and access allow |
| tags           | No        | Search terms such as performer, instrument, ritual, or theme |

The five planned entries should each have a named source. Media is optional so
the collection can still include older memories and stories without recordings.
