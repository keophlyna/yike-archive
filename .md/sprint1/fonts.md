# Sprint 1, Step 1 — Fonts

Instructions for Cline. Read fully before making any changes.

## Environment

Next.js 15 App Router, plain JavaScript, no TypeScript.

## Scope

Edit `app/fonts.js` only. Do not touch any other file.

## Task

Add these fonts via `next/font/google`, alongside the existing Montserrat (don't remove Montserrat):

- Fraunces
- Source Serif 4
- Noto Serif Khmer
- IBM Plex Mono

Export each the same way Montserrat is currently exported (as a variable with a `variable` name), so they can be used elsewhere later.

## Constraints

No new npm packages — `next/font/google` is built into Next.js.

## Output

Show the plan first — exactly what's being added to `app/fonts.js` — before writing code. Wait for approval.
